# Code of Conduct

This project follows the principles and enforcement guidelines of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Participants should be respectful, accept constructive feedback, and make collaboration welcoming regardless of background or identity. Harassment, discriminatory language, threats, sexualized attention, and publishing another person's private information are unacceptable.

This applies in project issues, pull requests, discussions, and other spaces where someone represents the project. Maintainers may remove harmful content, request a correction, restrict participation, or ban a participant, proportionate to the behavior and consistent with the Covenant's correction, warning, temporary-ban, and permanent-ban guidelines. Reports will be handled as privately as practical; absolute confidentiality cannot be promised.

For a conduct report, use a private contact method the maintainer publishes on their GitHub profile. If no private method is available, ask only for a private conduct-reporting channel in a public issue; withhold names and incident details until a private route is established. Security vulnerabilities use the separate process in [SECURITY](SECURITY.md).
